# 海盐账本 v1.2.0

这一版集中解决长期使用后的真实摩擦：六年账单下的明细卡顿、金额心算、全部账单统计，以及随手记账单迁移。

## 新增

- **金额计算器**：记账键盘支持 `+ − × ÷`，按运算优先级实时显示结果，保存时写入计算结果。
- **全部账单统计**：统计页新增「全部」模式，展示累计支出、累计收入、累计结余、跨年区间、全部年度走势、累计分类占比和排行。
- **随手记导入**：自动识别随手记来源，支持 `日期 / 收支 / 分类 / 子分类 / 金额 / 备注 / 账户 / 成员 / 项目` 等常见列。
- 导入页增加鲨鱼记账 / 随手记双教程和来源标签。

## 性能

- 新增月 / 年 / 日交易索引缓存，跨页面复用。
- 明细列表默认展示最近 10 天，按需加载更早的日期。
- 离屏日期组使用 `content-visibility` 延迟渲染。
- 13k 条合成账单下，从设置页切回「明细」的实测时间约 32ms，无长任务。

## 导入说明

### 鲨鱼记账

我的 → 设置 → 导出数据 / 导出账单，导出 CSV / Excel。

### 随手记

我的 → 设置 / 高级功能 → 备份与同步 → 导出数据 Excel。应用会优先使用「子分类」，并保留账户和备注。
