# 海盐账本 v1.2.1

这次更新集中修复导入账单的排序和长列表滚动问题，并把记账键盘调整为更接近鲨鱼记账的操作方式。

## 修复

- **同一天账单排序**：鲨鱼账单没有时间列时，按来源文件行号倒序，后记录的账单显示在前面。
- **滚动空白**：移除离屏日期组的 `content-visibility` 优化，修复快速滚动时日期组、记录甚至顶部卡片出现空白的问题。
- **导入入口**：统一改名为「导入旧账本」，继续支持鲨鱼记账和随手记。

## 新键盘

- 数字布局改为 `7-8-9 / 4-5-6 / 1-2-3 / .-0-退格`。
- 去掉乘除，保留加、减。
- 有运算时右下角显示「=」，点击后计算并显示结果；无运算时显示「完成」，点击等价于保存。
- 键盘上方增加备注入口和当前账户选择。
